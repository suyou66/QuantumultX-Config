# Quantumult X 零基础配置与排错教程（实测记录）

> 配套 PDF：《Quantumult_X_零基础图文配置与排错教程.pdf》，12 页 A4，使用本次真实操作截图。PDF 当前可从对话附件下载；尚未上传至此仓库。本文为同步的文字版。

## 适用范围与重要提醒

本教程记录一次 iPhone / iOS 27.0.1 / Quantumult X v1.8.1 build 951 的配置过程，帮助理解 GitHub ZIP、QX.conf、重写规则、MitM、证书信任和日志。只对有权测试的服务使用网络解密；不要将界面会员标识误当成服务端授权，也不要上传根证书私钥。

## 1. 下载项目并备份

原项目：https://github.com/7452323/QuantumultX

1. 在项目页面选择 Code → Download ZIP。
2. 在「文件」App 或电脑解压，查看 script/、.js 文件和说明。
3. 保留原 ZIP，不要直接覆盖原项目。
4. 检查脚本来源、目标域名、风险与维护情况。

**重点：下载 ZIP 不代表已经得到可直接导入的 Quantumult X 配置。**

## 2. 整理并导入配置

本次最终配置名为 `QX.conf`，存放在本仓库。远程路径示例：

`https://raw.githubusercontent.com/suyou66/QuantumultX-Config/main/QX.conf`

远程 raw 链接能否访问取决于仓库可见性、文件路径和网络条件。配置应包含 QX 能识别的必要配置节。导入后，本次显示 **68 条重写规则、30 条 MitM 主机名**，只是配置计数，**不等于脚本已执行**。

## 3. 先读日志，不要只看开关

本次曾出现：

- `No server existed, replaced with direct`：所选策略没有对应节点，连接回退 DIRECT；这和 MitM 证书问题不同。
- 网络活动显示 JS 计数 0：当时没有观察到 JS 执行；不代表配置一定无效。
- `MitM 所需根证书未安装，连接已断开`：明确指出系统尚未信任所需根证书。

正确验证顺序：**QX 运行 → 目标请求产生 → 命中重写 → HTTPS 解密 → JS 成功加载执行**。

## 4. 遇到「配置关联」限制怎么办

当出现「配置关联的状态下不允许该操作」或无法导入新配置时：

1. 进入 Quantumult X 配置界面。
2. 点击右上角**蓝色链条**图标。
3. 在「关联配置」中确认当前带勾的远程 GitHub 地址。
4. **先「拷贝配置」备份，再「取消关联」**。
5. 确认本地配置仍在，再尝试证书操作。

注意：取消关联可能改变当前生效配置，**不要直接删除原文件**。

## 5. 生成、安装并信任 MitM 根证书

这是本次排障最关键的一步。

**第一步：QX 内生成。** 打开 MitM →「生成证书」→「配置证书」。

**第二步：iOS 内安装。** 设置 → 通用 → VPN 与设备管理 → 安装刚才生成的 Quantumult X CA 描述文件。

**第三步：iOS 内信任。** 设置 → 通用 → 关于本机 → 证书信任设置 → 找到对应的 Quantumult X CA → 打开「针对根证书启用完全信任」。

本次证书显示为 `Quantumult X CA AAEB4B0D (20 Oct 2026)`。

**重点：已安装 ≠ 已信任。必须看到完全信任开关变成绿色。**

## 6. 验证结果

1. 返回 QX，确认配置仍在。
2. 打开「重写」和「MitM」，启动 QX 主开关。
3. 查看日志是否出现 `Tunnel started`，且不再报根证书未安装。
4. 在自己有权测试的服务上产生请求，检查重写是否命中及 JS 是否执行。

本次截图已证实：根证书完全信任、隧道正常启动、网络连接存在。部分 App 页面出现会员标识，但不能仅凭此证明服务端付费权益或某条脚本已执行。

## 7. 故障速查

| 提示/现象 | 优先检查 |
|---|---|
| 未生成证书 | 先点「生成证书」，再「配置证书」 |
| 安装后仍提示证书错误 | 「证书信任设置」中开关是否绿色 |
| 配置关联限制操作 | 蓝色链条 → 拷贝配置 → 取消关联 |
| 重写规则为 0 | 是否载入正确配置，配置节是否完整 |
| 重写规则有数量但 JS 为 0 | 请求是否出现、命中、解密及脚本加载 |
| No server existed | 节点及策略是否匹配 |

## 8. 安全建议

- 不要长期启用未知来源脚本，不要对银行、支付、登录等敏感域名随意启用 MitM。
- 公开 GitHub 仓库前检查配置中是否有账号、令牌、订阅地址、设备标识。
- 根证书私钥绝不能上传 GitHub。
- 按自己设备上的实际菜单操作，不同 QX/iOS 版本可能不同。
